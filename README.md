# Exam Backend Service

A Spring Boot backend for a proctored exam platform. This service provides REST APIs for user authentication, exam and question management, exam attempts, answer submission, and proctoring logs.

## Technology stack

- Java 25
- Spring Boot 4.0.6
- Spring Web MVC
- Spring Data JPA
- Spring Security
- PostgreSQL runtime driver
- Lombok
- JSON Web Tokens (JJWT)

## Project structure

- `src/main/java/com/proctoredExam/exam`
  - `controller/` - REST controllers for admin, auth, users, tests, questions, answers, exam attempts, and proctoring logs
  - `dto/` - request/response objects for API payloads
  - `entity/` - JPA entities and enums
  - `repository/` - Spring Data JPA repositories
  - `security/` - security configuration, JWT handling, and authentication logic
  - `service/` - business services and application logic
  - `config/` - application configuration classes
- `src/main/resources/` - Spring Boot application properties, static assets, and templates
- `src/test/java/` - unit/integration tests

## Requirements

- Java 25 or later
- Maven
- PostgreSQL database

## Build and run

From the project root:

```powershell
./mvnw clean package
./mvnw spring-boot:run
```

Or with Maven installed globally:

```powershell
mvn clean package
mvn spring-boot:run
```

## Configuration

Configure database and security settings in `src/main/resources/application.properties`.

Typical PostgreSQL settings:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/examdb
spring.datasource.username=youruser
spring.datasource.password=yourpassword
spring.jpa.hibernate.ddl-auto=update
```

## Notes

- The application uses JWT for authentication and Spring Security for protected endpoints.
- The `target/` directory is generated by Maven and should not be committed.
- `HELP.md` contains useful Spring Boot/Maven references and guide links.
